02 / SECURITY & PRIVACY

Protection is a practice.
Transparency matters.

A practical overview of the security mechanisms documented for Stellar ECC — what they are designed to do, and where their limits are.

✦
STELLAR ECC
SECURITY OVERVIEW
01

Message encryption

One-to-one conversations use the Signal Protocol with Double Ratchet. Group conversations use Sender Keys. These mechanisms are used to protect message content.

Signal ProtocolDouble RatchetSender Keys
02

Local device protection

Sensitive key material is stored through the platform secure-storage layer where supported. App access can be protected with the configured app PIN and device authentication.

03

Wanted Mode

Wanted Mode monitors selected local device and environment events, including USB, Bluetooth, network and power-related changes. Detected events can create a local security challenge or audit event.

04

Stellar GUARD — account removal

Stellar GUARD is designed as a protected workflow for requesting account removal using a six-digit verification code. The current Settings interface is preview-only; Continue is disabled and marked coming soon.

PREVIEW · COMING SOON
i

Wanted Mode events do not automatically wipe data or lock the app. The user can separately choose Lock now or Wipe local data and lock. Local wiping cannot erase copies already held by recipients or other devices.

04 / SECURITY GUIDANCE

Good security starts
with everyday habits.

Help protect your account and device with these recommended practices.

  • Never share your app PIN or verification codes.
  • Use a strong screen lock on your device.
  • Keep Stellar ECC and your operating system updated.
  • Protect your device and any backups.
  • Remember that local deletion cannot revoke information already delivered to another participant.
Understand the limits

No security feature can guarantee protection against every compromised device, operating-system vulnerability or physical attack. Monitoring cannot guarantee detection of every security incident.
